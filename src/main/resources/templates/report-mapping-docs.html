lightbulb Docxtemplater Integrator Guide

To create dynamic "Step X" formatting, you do not need to code logic in the template.
1. Wrap the section in {#reproductionSteps} ... {/reproductionSteps}.
2. Inside, write exactly {stepLabel}: {stepDescription}.
3. Style the tags directly in Word. Make {stepLabel} bold, red, and 14pt in Word. The engine will inherit your exact Word formatting for "Step 1", "Step 2", etc.
